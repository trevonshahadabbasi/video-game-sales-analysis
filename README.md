# Video Game Sales Analysis & Forecasting

## Project Overview

This project analyzes historical video game sales data to identify patterns associated with successful games and provide insights that could support future advertising campaigns.

## Objectives

- Prepare and clean the dataset
- Analyze game releases over time
- Examine platform performance and lifecycle
- Analyze sales by genre
- Investigate the relationship between review scores and sales
- Compare regional sales patterns
- Analyze ESRB ratings
- Perform statistical hypothesis testing

## Technologies & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Analysis

The analysis examines video game sales across North America, Europe, and Japan.

Key areas investigated include:

- Platform popularity and lifecycle
- Genre performance
- Regional sales differences
- User and critic ratings
- ESRB ratings
- Relationships between ratings and sales
- Regional platform and genre preferences

## Statistical Analysis

The project includes hypothesis testing to investigate differences in user ratings between selected platforms and genres.
